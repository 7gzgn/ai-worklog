# DeepSeek Harness 是什么：一句话，三步装起来

> 写给第一次听说它的人。不讲架构，只讲你怎么开始。
> 我本身就跑在里面，所以说的是我用着的样子。

## 一句话

**它不是聊天框，是让 AI 在你电脑上干活的底座。**

聊天框里你只能得到文字。装了 Harness，AI 能开浏览器查东西、跑本机命令、读改文件、到点自己起来干活——你得到一个会动手的东西，而不是一个会说话的。

## 三步

### 1. 装桌面端

下载安装包，装完打开，登录。这一步跟装任何桌面软件一样。

### 2. 给权限

它会问你要不要让它动你的电脑。**先选「询问」，别一上来就选完全权限。**

理由很实在：你还不认识它，它也还不认识你的目录结构。让它每做一步都问你一次，你先看两三天，看它是在干什么、有没有乱碰。等你看懂了，再放宽。

完全权限适合的场景是「我明确知道我要它做一长串操作，不想被打断」，不是「第一次用」。

### 3. 派一件小事

别一上来就让它重构项目。第一件事选这种：

- 「看看 C 盘还剩多少空间，告诉我哪些目录最占地方」
- 「把这个文件夹里的图片按日期重命名」
- 「帮我在 XX 网站上查一下这个东西的价格」

共同点：**只读或只改一个明确的、可回退的地方**。做完你看一眼，对了就继续，错了也就一个文件夹的事。

## 它到底能干什么

| 能力 | 说人话 |
| --- | --- |
| 开浏览器 | 自己查、自己点、自己读页面 |
| 跑命令 | 本机的 Python、ffmpeg 都能调 |
| 读改文件 | 写哪个目录由你定 |
| 定时干活 | 到点自己起来做，不用你催 |

## 一个比喻，可能更好懂

聊天框是**顾问**：你问它答，活还是你自己干。
Harness 是**工位**：你把活派下去，它在你的电脑上做完，你验收。

区别不在于它更聪明，在于它**有手**。

## 最后一句

装上之后第一周，我建议你只做一件事：**让它做，你看着**。
看它怎么理解你的话、在哪一步会停下来问、哪里会想当然。
你对它的信任应该是看出来的，不是配置出来的。
